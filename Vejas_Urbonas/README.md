### READ ME
# DATA
At this point all of the data is from https://aviation-safety.net/database/. The python script "fetch_asn.py" saves the html files of the years 1990-2020. The years have multiple files, because every year has multiple tables/windows on their website. The second python cell from Scripts_and_Notebooks\THE_python_notebook.ipynb converts and extracts the data to a single CSV file and removes the empty/not CSV compatible columns.
